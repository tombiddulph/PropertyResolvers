## Less ceremony. More C#.

```sh
dotnet add package PropertyResolvers --version 2.5.0
```

Select a property once. Use it across models you own—or models you don’t.

```csharp title="Assembly configuration and domain models"
using System;
using PropertyResolvers.Attributes;

[assembly: GeneratePropertyResolver("AccountId",
    Namespace = "Demo.Generated",
    Output = ResolverOutput.Typed)]

namespace Demo.Models;

public class Order { public Guid AccountId { get; init; } }
public class Invoice { public Guid AccountId { get; init; } }
```

```csharp title="Use the generated resolver"
using Demo.Generated;

// message can be an Order, Invoice, or any other eligible model.
if (AccountIdResolver.TryGet(message, out Guid accountId))
{
    Console.WriteLine(accountId);
}
```

No reflection, runtime binder, or shared interface. The generator discovers eligible types and emits ordinary type patterns and property access.

## Built for the edges

Inherited properties, partial types, keyword identifiers, nullable structs, and referenced assemblies all participate in semantic discovery. Invalid configurations get actionable diagnostics. Unrelated method edits reuse cached generation models.
